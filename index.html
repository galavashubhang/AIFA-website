Bridging the Engineering Gap

Traditional Failure Analysis

Visual inspection, fractography, and material testing remain heavily expert-dependent. The traditional process is manual, slow, and subjective—especially when initial evidence is incomplete.

  • High dependency on rare metallurgical experts.
  • Delayed root cause diagnosis during plant downtime.
  • Siloed case history without systematic reuse.

The AIFA Solution

Engineers need a structured first pass that can read images and context, retrieve precedent cases, ask the right follow-up questions, rank plausible causes, and recommend confirmatory tests.

  • Automated multimodal visual read & feature detection.
  • Source-cited reasoning grounded in 102+ real failure precedents.
  • Self-validating hypothesis generation without guesswork.
How FractoAI Works

5-Stage AI Investigation Pipeline

1

Upload Evidence

Component type, material (e.g., medium-carbon/low-alloy steel), manufacturer/model, failure description, and up to 5 fracture photos.

2

Visual Inspection (Agent 1)

Powered by Google Gemini 2.5 and CNN-based fracture mode classifiers (fatigue/brittle/ductile). Reads observed visual features with zero premature assumptions.

3

Targeted Investigation

Generates 5-8 targeted questions dynamically adapted to the visual evidence and operating history.

4

Hybrid Analysis & Knowledge Graph

Fuses image features + answers. Performs hybrid retrieval (Semantic + BM25 + Indicators) over a 102-case database with a knowledge graph tracing causal chains.

5

Engineering Output

Outputs ranked hypotheses with confidence levels, cited historical evidence, recommended lab validation tests, and a shareable report.

FASTAPI + LANGGRAPH STACK

Self-Validating Reasoning Moat

FractoAI is built on a LangGraph state machine orchestrating multi-agent LLM reasoning alongside embedding models for retrieval.

Deterministic Analysis Gate

Rule-based gate decides if a case is simple or deep, dictating necessary retrieval depth.

Critic Review Logic

Actively searches for counter-evidence against the leading hypothesis, forcing a pipeline revision if evidence doesn't hold.

Rigorous Testing

Validation & Real-World Accuracy

Internal System Checks

  • 70 Automated Tests: LangGraph orchestration, hybrid retrieval, and critic accept/revise logic verified.
  • Live Gemini API Smoke Tests: Catches live API model drift not visible in mocked environments.
  • 102 Case Corpus Check: Leave-one-out Top-1 / Top-3 accuracy measured across historical failure data.
  • Dataset Curation: Image augmentation pipeline with blurred and rotated variations for robust CNN training.

External Validation (MRPL Refinery)
